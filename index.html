Por que o erro "Invalid grant_type" acontece?

O Google bloqueou chamadas OAuth2 com JWT diretamente do navegador por segurança (política CORS + proteção de credenciais). A chave do Service Account nunca deve ficar exposta no frontend. A solução correta é usar uma Cloud Function — ela fica no servidor do Google, usa o Service Account com segurança e expõe apenas um endpoint simples para o painel chamar.

Tutorial Completo — Do Zero ao Celular Vibrando

PARTE 1

Instalar Node.js no seu computador

→ Acesse nodejs.org e baixe a versão LTS

→ Instale normalmente (Next, Next, Finish)

→ Abra o terminal e confirme:

node --version # deve mostrar v18 ou superior npm --version # deve mostrar 9 ou superior
PARTE 2

Instalar e configurar o Firebase CLI

→ No terminal, execute:

npm install -g firebase-tools

→ Faça login com sua conta Google:

firebase login

→ Vai abrir o navegador — aceite as permissões

→ Confirme que está logado:

firebase projects:list # Deve aparecer: alertateste-1a1b4
PARTE 3

Criar a Cloud Function

→ Crie uma pasta e entre nela:

mkdir fcm-functions cd fcm-functions

→ Inicie o projeto Firebase:

firebase init functions

Nas perguntas que aparecerem, responda:

• Use an existing project → selecione alertateste-1a1b4

• Language → JavaScript

• ESLint → N (não)

• Install dependencies → Y (sim)

→ Abra o arquivo functions/index.js e substitua todo o conteúdo por:

functions/index.js 
const { onRequest } = require("firebase-functions/v2/https");
const { initializeApp } = require("firebase-admin/app");
const { getMessaging } = require("firebase-admin/messaging");

// Inicializa o Firebase Admin (usa as credenciais automáticas)
initializeApp();

exports.sendNotification = onRequest(
  {
    // Região mais próxima do Brasil
    region: "southamerica-east1",
    // Permite chamadas do GitHub Pages (CORS)
    cors: true,
  },
  async (req, res) => {
    // Aceita apenas POST
    if (req.method !== "POST") {
      return res.status(405).json({ error: "Método não permitido" });
    }

    try {
      const { title, body, topic, token, tokens } = req.body;

      if (!title || !body) {
        return res.status(400).json({ error: "title e body são obrigatórios" });
      }

      const notification = { title, body };
      const android = {
        priority: "high",
        notification: {
          channelId: "event_alerts",
          sound: "default",
          defaultVibrateTimings: true,
          notificationPriority: "PRIORITY_HIGH",
          visibility: "PUBLIC",
        },
      };
      const apns = {
        payload: { aps: { sound: "default", badge: 1 } },
        headers: { "apns-priority": "10" },
      };

      let result;

      if (topic) {
        // Enviar para um tópico (todos os inscritos)
        result = await getMessaging().send({
          topic,
          notification,
          android,
          apns,
          data: { type: "EVENT_ALERT", ts: String(Date.now()) },
        });
        return res.json({ success: true, sent: 1, messageId: result });

      } else if (tokens && Array.isArray(tokens) && tokens.length > 0) {
        // Enviar para lista de tokens (máx 500 por vez)
        const chunks = [];
        for (let i = 0; i < tokens.length; i += 500) {
          chunks.push(tokens.slice(i, i + 500));
        }
        let totalOk = 0, totalFail = 0;
        for (const chunk of chunks) {
          const r = await getMessaging().sendEachForMulticast({
            tokens: chunk,
            notification,
            android,
            apns,
            data: { type: "EVENT_ALERT", ts: String(Date.now()) },
          });
          totalOk   += r.successCount;
          totalFail += r.failureCount;
        }
        return res.json({
          success: true,
          sent: totalOk,
          failed: totalFail,
        });

      } else if (token) {
        // Enviar para um token específico
        result = await getMessaging().send({
          token,
          notification,
          android,
          apns,
          data: { type: "EVENT_ALERT", ts: String(Date.now()) },
        });
        return res.json({ success: true, sent: 1, messageId: result });

      } else {
        return res.status(400).json({
          error: "Informe topic, token ou tokens[]",
        });
      }
    } catch (err) {
      console.error("Erro FCM:", err);
      return res.status(500).json({
        success: false,
        error: err.message,
        code: err.code,
      });
    }
  }
);
PARTE 4

Fazer o deploy da Cloud Function

→ No terminal (dentro da pasta fcm-functions):

firebase deploy --only functions

→ Aguarde 1–3 minutos. No final aparecerá algo como:

✔ functions[sendNotification(southamerica-east1)]: Successful! Function URL (sendNotification(southamerica-east1)): https://southamerica-east1-alertateste-1a1b4.cloudfunctions.net/sendNotification

Copie esta URL e cole na aba ⚙️ Configurações deste painel → Salvar.

PARTE 5

Ativar plano Blaze (obrigatório para deploy)

⚠️ O Firebase exige o plano Blaze para fazer deploy de Cloud Functions

O plano Blaze é pago conforme o uso, mas tem uma generosa cota gratuita. Para um evento, o custo será R$ 0,00 (as primeiras 2 milhões de chamadas por mês são gratuitas).

→ Acesse: Firebase Console → Uso e cobrança

→ Clique em Fazer upgrade → selecione Blaze

→ Adicione um cartão (não será cobrado dentro do limite gratuito)

→ Defina um limite de orçamento como R$ 5 para segurança

→ Volte ao terminal e execute o deploy novamente (Parte 4)

import 'package:flutter/material.dart';
import 'package:firebase_core/firebase_core.dart';
import 'package:firebase_messaging/firebase_messaging.dart';

// Handler para mensagens em background
@pragma('vm:entry-point')
Future<void> bgHandler(RemoteMessage msg) async {
  await Firebase.initializeApp();
  debugPrint('BG: ${msg.notification?.title}');
}

void main() async {
  WidgetsFlutterBinding.ensureInitialized();
  await Firebase.initializeApp();
  FirebaseMessaging.onBackgroundMessage(bgHandler);
  runApp(const EventoApp());
}

class EventoApp extends StatelessWidget {
  const EventoApp({super.key});
  @override
  Widget build(BuildContext context) => MaterialApp(
    title: 'Alertas Evento',
    debugShowCheckedModeBanner: false,
    theme: ThemeData(
      colorScheme: ColorScheme.fromSeed(
        seedColor: Colors.indigo,
        brightness: Brightness.dark,
      ),
    ),
    home: const AlertScreen(),
  );
}

class AlertScreen extends StatefulWidget {
  const AlertScreen({super.key});
  @override
  State<AlertScreen> createState() => _AlertScreenState();
}

class _AlertScreenState extends State<AlertScreen> {
  String _token = 'Carregando...';
  final List<Map<String, String>> _msgs = [];

  @override
  void initState() {
    super.initState();
    _setup();
  }

  Future<void> _setup() async {
    final fcm = FirebaseMessaging.instance;

    // 1. Pedir permissão (obrigatório iOS e Android 13+)
    final settings = await fcm.requestPermission(
      alert: true,
      badge: true,
      sound: true,
      announcement: true,
    );
    debugPrint('Permissão: ${settings.authorizationStatus}');

    // 2. Inscrever no tópico do evento
    await fcm.subscribeToTopic('evento2026');
    debugPrint('Inscrito no tópico: evento2026');

    // 3. Obter token único do dispositivo
    final token = await fcm.getToken();
    if (mounted) setState(() => _token = token ?? 'Erro');
    debugPrint('FCM Token: $token');

    // 4. Escutar mensagens com o app ABERTO (foreground)
    FirebaseMessaging.onMessage.listen(_onMessage);

    // 5. Quando o usuário toca na notificação (app em bg)
    FirebaseMessaging.onMessageOpenedApp.listen(_onMessage);

    // 6. Verificar se o app foi aberto por uma notificação
    final initial = await fcm.getInitialMessage();
    if (initial != null) _onMessage(initial);
  }

  void _onMessage(RemoteMessage msg) {
    final t = msg.notification?.title ?? 'Alerta';
    final b = msg.notification?.body  ?? '';
    final ts = '${DateTime.now().hour}:${DateTime.now().minute.toString().padLeft(2, '0')}';
    if (mounted) {
      setState(() => _msgs.insert(0, {'title': t, 'body': b, 'time': ts}));
    }
  }

  @override
  Widget build(BuildContext context) => Scaffold(
    backgroundColor: const Color(0xFF0A0C1A),
    appBar: AppBar(
      title: const Text('🔔 Alertas do Evento'),
      backgroundColor: const Color(0xFF131630),
      elevation: 0,
    ),
    body: Padding(
      padding: const EdgeInsets.all(16),
      child: Column(
        crossAxisAlignment: CrossAxisAlignment.start,
        children: [
          // ── Token Card ───────────────────────────────────
          Container(
            width: double.infinity,
            padding: const EdgeInsets.all(14),
            decoration: BoxDecoration(
              color: Colors.indigo.withOpacity(.1),
              border: Border.all(color: Colors.indigo.withOpacity(.3)),
              borderRadius: BorderRadius.circular(14),
            ),
            child: Column(
              crossAxisAlignment: CrossAxisAlignment.start,
              children: [
                Row(
                  children: [
                    const Icon(Icons.phonelink_ring,
                      color: Colors.indigoAccent, size: 14),
                    const SizedBox(width: 6),
                    const Text('Token FCM deste dispositivo:',
                      style: TextStyle(color: Colors.white54, fontSize: 11)),
                  ],
                ),
                const SizedBox(height: 6),
                SelectableText(_token,
                  style: const TextStyle(
                    fontSize: 10,
                    fontFamily: 'monospace',
                    color: Colors.greenAccent,
                  ),
                ),
                const SizedBox(height: 6),
                const Text(
                  '✓ Inscrito no tópico: evento2026',
                  style: TextStyle(
                    color: Colors.green, fontSize: 11,
                    fontWeight: FontWeight.w500,
                  ),
                ),
              ],
            ),
          ),
          const SizedBox(height: 16),

          const Text('📬 Alertas Recebidos:',
            style: TextStyle(
              fontWeight: FontWeight.bold,
              color: Colors.white,
              fontSize: 14,
            )),
          const SizedBox(height: 8),

          Expanded(
            child: _msgs.isEmpty
              ? Center(
                  child: Column(
                    mainAxisSize: MainAxisSize.min,
                    children: [
                      Icon(Icons.notifications_none,
                        size: 48, color: Colors.white.withOpacity(.2)),
                      const SizedBox(height: 8),
                      Text('Aguardando alertas...',
                        style: TextStyle(
                          color: Colors.white.withOpacity(.3),
                          fontSize: 14)),
                    ],
                  ),
                )
              : ListView.builder(
                  itemCount: _msgs.length,
                  itemBuilder: (_, i) => Container(
                    margin: const EdgeInsets.only(bottom: 8),
                    padding: const EdgeInsets.all(13),
                    decoration: BoxDecoration(
                      color: Colors.white.withOpacity(.05),
                      borderRadius: BorderRadius.circular(12),
                      border: Border.all(
                        color: Colors.white.withOpacity(.07)),
                    ),
                    child: Row(
                      crossAxisAlignment: CrossAxisAlignment.start,
                      children: [
                        Expanded(
                          child: Column(
                            crossAxisAlignment: CrossAxisAlignment.start,
                            children: [
                              Text(_msgs[i]['title']!,
                                style: const TextStyle(
                                  fontSize: 13,
                                  fontWeight: FontWeight.bold,
                                  color: Colors.white,
                                )),
                              if (_msgs[i]['body']!.isNotEmpty) ...[
                                const SizedBox(height: 2),
                                Text(_msgs[i]['body']!,
                                  style: TextStyle(
                                    fontSize: 12,
                                    color: Colors.white.withOpacity(.6),
                                  )),
                              ],
                            ],
                          ),
                        ),
                        Text(_msgs[i]['time']!,
                          style: TextStyle(
                            fontSize: 11,
                            color: Colors.white.withOpacity(.3),
                          )),
                      ],
                    ),
                  ),
                ),
          ),
        ],
      ),
    ),
  );
}
